## 判读方式

| 标记 | 可以证明什么 | 不能据此推导什么 |
| --- | --- | --- |
| 历史实测 | 指定日期、构建和目标站点的实际开发态/平台结果 | 本轮、现版其它菜单、其它账号或全平台通过 |
| 离线回放 | 生产模块在合成状态机、脱敏 DOM 或模拟网络下的行为 | 真实点击/按键、服务端路由、真实 Drive 或账号可用 |

| 本轮真实验证 | 本轮实际执行且注明版本、平台、站点、用例的结果 | 未执行的能力与环境 |
| 待验证 / 受阻 | 缺少目标环境，或该轮未通过、未确认、页面未就绪 | 产品必然故障；也不能用更早的通过覆盖此状态 |

页面可用指页面、输入框及必要 control 的现场证据；不要求 `tier`、`capture` 全绿。切档指生产 `__AMS` 的当次确认，不等于关闭菜单后一定有可读 `state()`。文字/图片列指实际提交，生成列另核对生成信号和完成判定；提交、生成完成与回答归属/采集是三项独立结果。网页上的模型名称仅为观测，不是服务端模型路由证明。
