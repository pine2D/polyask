PolyAsk Portable

English

Start: App\polyask-desktop.exe

To upgrade:
1. Quit every running PolyAsk process completely.
2. Replace the entire App folder with the new App folder (do not copy single files inside it).
3. Keep PolyAsk Data (it holds your settings, site sign-ins, and saved work).

portable.json and README.txt contain no user data and are safe to overwrite.
If another PolyAsk installation exists on this computer, first launch lets you copy its settings and sign-ins without modifying the original.

简体中文

启动：App\polyask-desktop.exe

升级方法：
1. 完全退出正在运行的 PolyAsk。
2. 用新版整个 App 文件夹替换旧 App 文件夹（不要只替换里面的单个文件）。
3. 保留 PolyAsk Data 文件夹（内含设置、站点登录状态和本机记录）。

portable.json 与 README.txt 不含个人数据，可直接覆盖。
若本机装过其他版本的 PolyAsk，首次启动可复制其设置与登录状态，原有数据保留不动。

繁體中文

啟動：App\polyask-desktop.exe

升級方式：
1. 完全關閉執行中的 PolyAsk。
2. 用新版整個 App 資料夾取代舊 App 資料夾（不要只取代裡面的單一檔案）。
3. 保留 PolyAsk Data 資料夾（內含設定、網站登入狀態與本機資料）。

portable.json 與 README.txt 不含個人資料，可直接覆寫。
若本機裝過其他版本的 PolyAsk，首次啟動可複製其設定與登入狀態，原有資料保留不動。
